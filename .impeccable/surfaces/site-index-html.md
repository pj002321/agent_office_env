# Promo site (site/index.html)

Scope: public landing + download page for the desktop app. Mode: Persuade.
Audience: developers who already run Claude Code / Codex CLIs in terminals. Job: understand "your CLIs become a cozy office you command", trust it (runs your own CLI, never touches credentials, you approve changes), download for their OS.
Constraints: Korean copy; never "Claude"/"Anthropic" in product name or logo (compatibility statements are fine); no invented users, metrics, prices, or testimonials; downloads point at GitHub Releases `latest/download/AgentOffice-Setup.exe` and `AgentOffice-mac.dmg`.
Reference the user pinned: railway.com structure (painted-sky hero, centered serif-scale headline, two buttons, big product window with a tab pill that swaps scenes; features as stops along a vertical rail with a moving vehicle; tinted section bands).
